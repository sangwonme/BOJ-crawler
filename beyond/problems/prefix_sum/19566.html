19566. 수열의 구간 평균

길이가 N인 수열 A_1, A_2, \cdots, A_N이 주어진다. 구간에 있는 모든 수들의 평균이 정확히 K인 구간의 개수를 구해 보자.

입력

첫째 줄에 수열의 크기 N과 우리가 원하는 평균 K가 주어진다. (1 ≤ N ≤ 200,000, -10^9 ≤ K ≤ 10^9)

둘째 줄에는 수열 A_1, A_2, \cdots, A_N이 주어진다. (1 ≤ i ≤ N, -10^9 ≤ A_i ≤ 10^9)

입력에 주어지는 모든 수들은 정수이다.

출력

구간에 존재하는 모든 수의 평균이 K인 구간의 개수를 출력한다.

예제 입출력

예제 1

Input:

4 2
1 3 2 2

Output:

6

예제 2

Input:

10 3
2 4 3 1 5 3 2 4 1 3

Output:

19
